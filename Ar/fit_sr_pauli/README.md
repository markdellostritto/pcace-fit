Scripts:
* run_train_cpu.sh - train potential on cpu
* run_train_cuda.sh - train potential on CUDA
* run_eval_cpu.sh - evaluate potential on training data on cpu
* run_eval_cuda.sh - evaluate potential on training data on CUDA
* run_md_cpu.sh - run simulation using trained model on cpu
* run_md_cuda.sh - run simulation using trained model on CUDA
* save_info.sh - save training data in plottable format

GNUPlot Plotting scripts are provided for plotting the training
error, structure energies, structure forces, and learning rate.
